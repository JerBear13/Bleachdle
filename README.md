# Bleachdle
Its like playing wordle but instead its guessing bleach characters, it's somewhat incomplete but the fundamentals are there. 

<h1>HOW TO USE THIS PROJECT</h1>
1. Download the Folder
2. Open an IDE of your choice 
3. Once you're in that IDE, click on open a new folder
4. Click on the Anime Wordle  Folder
5. Once it is opened click run and follow instructions in the consle 
6. When you click run on the code you will type the name of the guess in the text box and a drop down menu will appear as you type out a name. 
7. Once you have a name you need to click on the text box again the npress enter for your guess to go through.
8. have fun guessing!
